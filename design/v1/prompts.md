# Prompts de generación · Stunafy v1

Motor: herramienta integrada ImageGen. No se ha utilizado CLI ni API con clave propia.

Los logos se generaron individualmente y se revisaron para quitar efectos de brillo. El promotor eligió después la referencia externa “Pandereta española con ondas rojas”; las maquetas actualizadas la usan como recurso exacto. La adaptación móvil utilizó la maqueta de escritorio como referencia visual.

## Logo elegido · referencia aplicada

Fuente: [ChatGPT · Pandereta española con ondas rojas](https://chatgpt.com/s/m_6a9c42a5279c81918cc0358e41eec2db). Archivo local: `logo-elegido-pandereta-roja.png`.

En cualquier nueva maqueta debe colocarse el archivo como referencia, conservar su silueta y evitar reinterpretaciones, brillos añadidos o símbolos parecidos a Spotify. El rojo indicado en la documentación es una aproximación visual para prototipos; la paleta final se medirá sobre el archivo vectorial de producción.
